# C++ 物件導向(OOP)－多型與虛擬函式

## 一、多型與虛擬函式

> 💡 **前置知識**
> 多型是物件導向的深入觀念。學習本章前，建議先**看懂並熟練**前面「物件導向基本觀念」與「繼承」的內容，
> 尤其要確實理解 **類別、物件與名稱** 之間的關係。

### 多型的定義

多型的實作，指的是 **父類別宣告的指標或參考**，可以控制所有子類別物件。

也就是說：

> ✅ **父類別宣告的指標或參考，可以代表任何子類別物件。**

---

## 二、觀念 Q&A

### Q1. 多型的目的？

**A.** 用**父類別宣告的指標或參考**呼叫成員函式時，會依照**實際指向的物件不同**，而得到**不同的執行結果**。

- 好處：同一段程式碼可以處理所有子類別物件，避免為每個子類別各寫一個 **Overload（多載）** 版本。

```cpp
class Mouse {
public:
    virtual void click() { cout << "滑鼠點擊" << endl; }
    virtual ~Mouse() {}
};

class OpticalMouse : public Mouse {
public:
    void click() override { cout << "光學滑鼠點擊" << endl; }
};

void use(Mouse& m) { m.click(); }   // 一個函式就夠，不必為每個子類別多載

OpticalMouse om;
use(om);   // 輸出：光學滑鼠點擊
```

> ⚠️ 父類別的函式必須宣告為 `virtual`，透過指標／參考呼叫時才會執行子類別的版本。

---

### Q2. 什麼是 is-a？

**A.** 描述 **類別與類別** 之間的**繼承**關係：

> **子類別 is-a 父類別**（有繼承就成立）

**例：**

```
無線光學滑鼠 is-a 光學滑鼠 is-a 滑鼠 is-a 電腦週邊 is-a 電子設備
```

**重點：** 因為子類別 is-a 父類別，所以**子類別型別的物件**，同時也是**父類別型別的物件** → 這正是父類別指標／參考能指向子類別物件的原因。

---

### Q3. 什麼是物件多型？

**A.** 每個物件都有型別，而且**同時擁有多種型別**；這些型別之間必定是 **父子（繼承）** 關係。

| 物件 | 型別鏈（子 → 父） |
| --- | --- |
| 你身上的手機 | 智慧型手機 → 行動電話 → 電話 → 電子設備 |
| 你桌上的滑鼠 | 無線光學滑鼠 → 光學滑鼠 → 滑鼠 → 電腦週邊 → 電子設備 |

以滑鼠為例，你桌上的那一支滑鼠**同時是**：無線光學滑鼠、光學滑鼠、滑鼠、電腦週邊、電子設備 型別的物件。

```cpp
WirelessOpticalMouse m;
OpticalMouse&    r1 = m;   // ✅ 它是光學滑鼠
Mouse&           r2 = m;   // ✅ 它是滑鼠
ComputerDevice*  p  = &m;  // ✅ 它是電腦週邊
```

---

### Q4. 什麼是 has-a？

**A.** 描述 **類別與類別** 之間的**組合**關係：

> 在 A 類別中用 B 類別宣告**成員變數**，就可以說 **A has-a B**。

**例：** 電腦 has-a CPU → 一個「電腦」物件裡，包含一個「CPU」物件。

```cpp
class CPU { /* ... */ };

class Computer {
    CPU cpu;   // Computer has-a CPU
};
```

---

## 三、is-a vs has-a 比較

| 關係 | 意義 | 實作方式 | 例子 | 判斷口訣 |
| --- | --- | --- | --- | --- |
| **is-a** | 「是一種」 | 繼承 | 光學滑鼠 is-a 滑鼠 | 「A 是一種 B」說得通 |
| **has-a** | 「擁有一個」 | 成員變數（組合） | 電腦 has-a CPU | 「A 裡面有 B」說得通 |

## 四、多型的指派與呼叫

### 1. 指派方式

| 方式 | 說明 | 是否為多型 |
| --- | --- | --- |
| **物件變數** | 子類別物件 → 父類別物件變數 | ❌ 只是**物件複製**（子類別多出的部分會被切掉） |
| **A. 指標** | 子類別物件 → 父類別指標 | ✅ |
| **B. 參考** | 子類別物件 → 父類別參考 | ✅ |
| **C. 集合** | 子類別物件 → 父類別型別的集合（如陣列、`vector`） | ✅（集合內要存指標） |
| **D. 參數** | 子類別物件 → 父類別型別的函式參數 | ✅（參數要是指標或參考） |

```cpp
OpticalMouse om;

Mouse  m  = om;    // ❌ 物件複製，不是多型
Mouse* p  = &om;   // ✅ 指標
Mouse& r  = om;    // ✅ 參考
vector<Mouse*> list = { &om };   // ✅ 集合
void use(Mouse& m);              // ✅ 參數
```

### 2. 函式呼叫：只看「宣告的型別」

無論是物件變數、參考或指標，**都只能呼叫父類別中有的成員**；子類別自己新增的成員呼叫不到。

### 3. 函式執行：沒有 `virtual` 時

就算子類別定義了同名的成員函式，透過物件變數、參考或指標呼叫時，**一律執行父類別的版本**。
→ 要讓子類別的版本被執行，就需要下一節的**虛擬函式**。

---

## 五、虛擬函式

### 1. 父類別

| 項目 | 寫法 |
| --- | --- |
| **A. 宣告與定義虛擬函式** | 在函式宣告前加上關鍵字 `virtual` |
| **B. 宣告虛擬解構函式** | `virtual ~ClassName() {}` |

> ⚠️ 有虛擬函式的父類別，解構函式也應宣告為 `virtual`，否則透過父類別指標 `delete` 子類別物件時，子類別的解構函式不會被呼叫。

### 2. 子類別

| 項目 | 說明 |
| --- | --- |
| **A. Override 父類別的虛擬函式** | 重新宣告並定義父類別中的虛擬函式（建議加上 `override`） |
| **B. 用多型指標呼叫虛擬函式** | 執行**子類別** Override 的內容 |
| **C. 用多型參考呼叫虛擬函式** | 執行**子類別** Override 的內容 |

> 範例見 [Q1. 多型的目的](#q1-多型的目的)。

### 3. `dynamic_cast`：把父類別指標／參考轉回子類別

| 對象 | 語法 | 轉型失敗時 |
| --- | --- | --- |
| **A. 指標** | `dynamic_cast<Type*>(pointer)` | 結果為 `nullptr`（0） |
| **B. 參考** | `dynamic_cast<Type&>(reference)` | 拋出例外 `std::bad_cast` |

```cpp
Mouse* p = &om;
if (OpticalMouse* op = dynamic_cast<OpticalMouse*>(p)) {
    // 轉型成功，可以使用 OpticalMouse 才有的成員
}
```

> 💡 `dynamic_cast` 只能用在**至少有一個虛擬函式**的類別上。

## 六、純虛擬函式與抽象類別

### 1. 宣告純虛擬函式

```cpp
virtual type name(parameter list) = 0;
```

### 2. 抽象類別

類別中若**宣告或繼承**了一個以上的純虛擬函式（且尚未被 Override），這個類別就是**抽象類別**。

| 特性 | 說明 |
| --- | --- |
| **A. 不可建立物件** | `Shape s;` ❌ 編譯錯誤 |
| **B. 可作為多型的型別** | `Shape* p = &circle;` ✅ |

```cpp
class Shape {
public:
    virtual double area() = 0;   // 純虛擬函式
    virtual ~Shape() {}
};

class Circle : public Shape {
    double r = 1;
public:
    double area() override { return 3.14159 * r * r; }
};

Circle c;
Shape* p = &c;   // ✅ 抽象類別當多型型別
p->area();       // 執行 Circle::area
```
